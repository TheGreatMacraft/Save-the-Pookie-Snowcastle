
# Core System
- each weapon will have it's own default attack and heavy attack
- it's ability will be dictated by another *charm/talisman* that will effect the attack
- pressing the secondary button will activate the secondary tool - that won't be a weapon, but some support for the player (grapple hook, movement boost, invisibility, etc.)

# Guns

	- *Default attack*: slow, short range, multiple fast bullet blast
	- *Heavy attack*: big range, fewer fast bullet blast
